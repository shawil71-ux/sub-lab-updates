# SUB-LAB updates

Finished builds of SUB-LAB for the TrimUI Brick (no source code here).

- **First install / cable install:** download `SUB-LAB-trimui.zip`, unzip it, and copy the `SUB-LAB` folder into the SD card's `Apps` folder.
- **Wi-Fi updates:** in SUB-LAB, open the yellow folder > **Update SUB-LAB (Wi-Fi)**. It reads `trimui/manifest.txt` and downloads only the files that changed.
